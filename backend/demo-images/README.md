# Demo listing photos

Put one photo per demo listing in this folder, then run `npm run seed:demo` (from the `backend` folder).
Running it again later adds photos to demo listings that do not have one yet. Nothing else changes.

- File names: `demo-01.jpg` … `demo-30.jpg` (`.jpeg`, `.png` and `.webp` also work).
- Each file must be a real JPEG, PNG or WebP image, **5 MB or smaller**. Square or portrait photos (e.g. 800×1000) look best on the cards.
- Use photos you own or that are free to use (e.g. your own photos, or images under a free licence). Check `npm run seed:demo:dry` to see which are found.
- A missing photo is not an error: that listing just shows the app's placeholder.
